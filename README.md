# Media Archive Tooling

Tools and scripts for processing media files in our archive.

## Overview

This repository collects utilities for working with the media archive, such as:

- Ingesting and organizing media files
- Extracting and normalizing metadata
- Transcoding and generating derivatives (proxies, thumbnails)
- Validating files and checking integrity (checksums, corrupt-file detection)

## Getting started

```bash
git clone <repo-url>
cd Media-Archive-Tooling-Claude
```

Setup and usage instructions for individual tools will be added as they are developed.

## Project structure

```
.
```

## Notes

Media files themselves (video, audio, images) are not stored in this repository — see `.gitignore`. Keep the archive's source files in their own storage and point the tools at them.
